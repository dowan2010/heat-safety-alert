# 폭염 안심 알리미

직접 잰 기온과 습도로 **체감온도**를 계산하고, 기상청 폭염 영향예보 기준에 따라 위험 단계와 행동요령을 알려주는 웹 앱입니다. 학교 장소(운동장·교실·체육관·기숙사 등)별 측정 기록을 저장하고 비교할 수 있습니다.

## 기능

- **실시간 계산**: 기온·습도를 입력하면 바로 체감온도와 위험 단계를 표시
- **위험 단계**: 관심 31℃ · 주의 33℃ · 경고 35℃ · 위험 38℃
- **행동요령**: 단계별 물 마시기, 휴식, 활동 중단 안내
- **기록 저장**: 일시·장소·활동과 함께 브라우저(localStorage)에 저장
- **비교**: 장소별·시간대별 평균 체감온도

## 체감온도 계산식 (기상청 여름철)

```
Tw = Stull 습구온도(Ta, RH)
체감온도 = −0.2442 + 0.55399·Tw + 0.45535·Ta − 0.0022·Tw² + 0.00278·Tw·Ta + 3.0
```

## 페이지 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 소개, 작동 방식 |
| `measure.html` | 측정 계산기 |
| `levels.html` | 위험 단계 |
| `records.html` | 장소·시간대 비교, 기록 목록 |
| `style.css`, `app.js` | 공통 스타일·스크립트 |

## 실행

빌드 없이 정적 파일로 동작합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 을 엽니다.
